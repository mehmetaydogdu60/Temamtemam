# Samsun WordPress Teması

Modern ve profesyonel WordPress teması. **samsunsporluyuz.com** için özel olarak tasarlandı.

## 📦 İndirme

WordPress temasını kullanmak için `samsun.zip` dosyasını indirin.

## ✨ Özellikler

- ✅ **Tamamen Responsive** - Tüm cihazlarda mükemmel görünüm
- ✅ **Renk Özelleştirme** - WordPress Customizer ile kolay renk ayarları
- ✅ **Widget Desteği** - Sidebar + 3 Footer Widget Alanı
- ✅ **Menü Desteği** - Ana Menü + Footer Menü
- ✅ **Modern Tasarım** - CSS Grid ve Flexbox kullanımı
- ✅ **SEO Uyumlu** - Arama motorları için optimize
- ✅ **Hızlı ve Optimize** - Performans odaklı kod
- ✅ **Türkçe Dil Desteği** - Tam Türkçe arayüz
- ✅ **Gutenberg Uyumlu** - Modern WordPress editör desteği
- ✅ **RTL Desteği** - Sağdan sola dil desteği

## 🚀 Kurulum

1. `samsun.zip` dosyasını indirin
2. WordPress yönetim panelinde **Görünüm > Temalar > Yeni Ekle** menüsüne gidin
3. "Tema Yükle" butonuna tıklayın
4. `samsun.zip` dosyasını seçin ve yükleyin
5. Temayı aktif edin

### Alternatif Kurulum (FTP)

1. `samsun.zip` dosyasını bilgisayarınızda açın
2. `samsun` klasörünü FTP ile `wp-content/themes/` dizinine yükleyin
3. WordPress yönetim panelinde **Görünüm > Temalar** menüsünden aktif edin

## 🎨 Özelleştirme

WordPress yönetim panelinde **Görünüm > Özelleştir** menüsüne giderek temayı özelleştirebilirsiniz:

### Renk Ayarları
- **Ana Renk** - Varsayılan: #e30613 (Kırmızı)
- **İkincil Renk** - Varsayılan: #1a1a1a (Koyu Gri)
- **Vurgu Rengi** - Varsayılan: #ffd700 (Altın)
- **Metin Rengi** - Varsayılan: #333333
- **Link Rengi** - Varsayılan: #e30613

### Düzen Ayarları
- **Container Genişliği** - 960px - 1920px arası ayarlanabilir
- **Sidebar Konumu** - Sol veya Sağ

### Tipografi
- **Ana Font Boyutu** - 12px - 24px arası

### Logo ve Site Kimliği
- Logo yükleme
- Site başlığı ve açıklaması
- Site ikonu (Favicon)

## 📱 Widget Alanları

Tema **4 widget alanı** içerir:

1. **Sidebar** - Ana içerik yanında görünür
2. **Footer Widget 1** - Footer ilk sütun
3. **Footer Widget 2** - Footer ikinci sütun
4. **Footer Widget 3** - Footer üçüncü sütun

Widget eklemek için **Görünüm > Widget'lar** menüsünü kullanın.

## 🔗 Menü Konumları

Tema **2 menü konumu** destekler:

1. **Primary Menu** - Header'da görünür ana menü (Alt menü desteği var)
2. **Footer Menu** - Footer'da görünür menü

Menü oluşturmak için **Görünüm > Menüler** menüsünü kullanın.

## 🎯 Kullanım Örnekleri

### Widget Ekleme
1. **Görünüm > Widget'lar** menüsüne gidin
2. İstediğiniz widget'ı sürükleyin
3. Widget alanlarından birini seçin (Sidebar, Footer 1-3)
4. Kaydet

### Menü Oluşturma
1. **Görünüm > Menüler** menüsüne gidin
2. Yeni menü oluşturun
3. Sayfa/yazı/kategori ekleyin
4. "Primary Menu" veya "Footer Menu" konumunu seçin
5. Kaydet

### Logo Yükleme
1. **Görünüm > Özelleştir** menüsüne gidin
2. "Site Kimliği" bölümüne tıklayın
3. "Logo Seç" butonuna tıklayın
4. Logonuzu yükleyin (Önerilen: 200x60px)
5. Yayınla

## 🐛 Sorun Giderme

### Menü Görünmüyor
- **Görünüm > Menüler** bölümünden menü konumu atadığınızdan emin olun

### Widget'lar Görünmüyor
- Tema aktif olduğundan emin olun
- Widget alanlarına widget eklediğinizden emin olun

### Renkler Değişmiyor
- Tarayıcı cache'ini temizleyin
- Customizer'dan renkleri kaydettiğinizden emin olun
