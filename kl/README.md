# Samsun WordPress Teması

Modern ve profesyonel WordPress teması. Samsunsporluyuz.com için özel olarak tasarlandı.

## Özellikler

- ✅ Tamamen Responsive (Mobil Uyumlu)
- ✅ WordPress Customizer ile Renk Özelleştirme
- ✅ Widget Desteği (Sidebar + 3 Footer Widget Alanı)
- ✅ Menü Desteği (Ana Menü + Footer Menü)
- ✅ Öne Çıkan Görsel Desteği
- ✅ Custom Logo Desteği
- ✅ SEO Uyumlu
- ✅ Hızlı ve Optimize Edilmiş
- ✅ Modern CSS Grid ve Flexbox Kullanımı
- ✅ Smooth Scroll ve Animasyonlar
- ✅ Yorum Sistemi
- ✅ Arama Fonksiyonu
- ✅ Türkçe Dil Desteği
- ✅ Pagination
- ✅ Custom Post Types Desteği
- ✅ Gutenberg Uyumlu

## Kurulum

1. `samsun` klasörünü WordPress kurulumunuzun `wp-content/themes/` dizinine yükleyin
2. WordPress yönetim panelinde **Görünüm > Temalar** menüsüne gidin
3. "Samsun" temasını aktif edin

## Özelleştirme

WordPress yönetim panelinde **Görünüm > Özelleştir** menüsüne giderek temayı özelleştirebilirsiniz:

### Renk Ayarları
- Ana Renk (Primary Color)
- İkincil Renk (Secondary Color)
- Vurgu Rengi (Accent Color)
- Metin Rengi
- Link Rengi

### Düzen Ayarları
- Container Genişliği (960px - 1920px)
- Sidebar Konumu (Sol/Sağ)

### Tipografi
- Ana Font Boyutu (12px - 24px)

### Footer Ayarları
- Özel Footer Metni

### Logo ve Site Kimliği
- Logo Yükleme
- Site Başlığı
- Site Açıklaması
- Site İkonu (Favicon)

## Widget Alanları

Tema 4 widget alanı içerir:

1. **Sidebar** - Ana içerik yanında görünür
2. **Footer Widget 1** - Footer'ın ilk sütunu
3. **Footer Widget 2** - Footer'ın ikinci sütunu
4. **Footer Widget 3** - Footer'ın üçüncü sütunu

Widget eklemek için **Görünüm > Widget'lar** menüsünü kullanın.

## Menü Ayarları

Tema 2 menü konumu destekler:

1. **Primary Menu** - Header'da görünür ana menü
2. **Footer Menu** - Footer'da görünür menü

Menü oluşturmak için **Görünüm > Menüler** menüsünü kullanın.

## Sayfa Şablonları

- `index.php` - Ana sayfa ve blog arşivi
- `single.php` - Tekil yazı sayfası
- `page.php` - Sayfalar
- `archive.php` - Kategori, etiket ve tarih arşivleri
- `search.php` - Arama sonuçları
- `404.php` - Hata sayfası

## Özel Görsel Boyutları

- `samsun-featured` - 1200x600px (Öne çıkan görseller için)
- `samsun-thumbnail` - 400x300px (Küçük görseller için)
